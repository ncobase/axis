# @ncobase/scaffold

Project scaffolding and code generation utilities for Ncobase applications.

## Current Status

`@ncobase/scaffold` is a private placeholder package in the `axis` workspace. It is reserved for
future project, component, feature, schema, API, and form-builder generators.

The active feature scaffolding implementation currently lives in the console application builder:

- `frontend/apps/console/src/features/builder/feature`

Do not treat this package as a production generator until it has a real CLI or programmatic API,
tests, and documentation.

## Planned Scope

- Project template generation
- Component scaffolding
- Feature module generation
- Database schema generation
- API endpoint generation
- Form builder scaffolding
